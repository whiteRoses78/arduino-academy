# arduino-academy

SaaS-Webapp für interaktives Arduino-/Mikrocontroller-Lernen (Realschul-Abschlussprüfung Technik, BW). Multi-User mit Login; Fortschritt, Spaced Repetition und Selbsteinschätzung werden pro Nutzer in Supabase gespeichert. Transformation der bestehenden Vanilla-Lernapp (17+ Lektionen, 5 Module).

## Local Development

```bash
npm install
npm run dev
```

Lokale Env-Vars in `.env.local` (siehe `.env.example`).
